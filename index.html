Featured project

Riverview Premier Academy

School website, parent portal & management system · Utawala, Nairobi · 2026

Visit live site ↗ Client project · code private

A complete digital system for a CBC school (Playgroup to Grade 9): the public website parents find on Google, a secure parent portal, an admin panel for staff, SMS and email notifications, and an AI assistant that answers parents' questions. I built it end to end and run it in production on a Linux server.

🌐 Public website

  • About 20 pages: admissions with online application, fees, transport, news, events, gallery with YouTube videos
  • Computer Studies and French syllabuses, class by class
  • SEO: indexed on Google, structured data, sitemap, share previews
  • Mobile-friendly design in the school's colours

🔐 Parent portal

  • Login by admission number, forced password change, lockout after failed attempts
  • Fee statements, CBC results, report cards, attendance, homework
  • Teacher–parent messaging
  • Phone number confirmation by SMS code

🛠️ Admin panel

  • Content management for news, events, gallery, staff, downloads and fees
  • Excel import of learners, class promotion, bulk fee charges, printable login slips
  • Multiple staff logins with optional SMS two-step login

📲 SMS & email notifications

  • Personalised fee reminders with each child's balance
  • Reopening dates, announcements and emergency alerts
  • Scheduled sending, delivery reports and cost tracking
  • Africa's Talking SMS API and Gmail SMTP

🤖 AI assistant

  • "Ask RPA" chat widget that answers parents from the school's own pages
  • Claude API with prompt caching, rate limits and a daily budget
  • Question log so the school can see what parents ask

☁️ Hosting & operations

  • Ubuntu VPS with Gunicorn and systemd
  • Cloudflare Tunnel, HTTPS, firewall, SSH-key only access
  • Nightly automatic backups and one-command deployments
  • Automated test suite run before every release
